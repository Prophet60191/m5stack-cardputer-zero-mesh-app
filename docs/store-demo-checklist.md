# First Store submission video

The owner will record this on the actual CardputerZero. Aim for roughly 60–90
seconds. Show the real installed app, not only a simulator or synthetic replay.
The official first-submission guide asks for launch, main features and exit.

## Before recording

- Use the qualified candidate and confirm its version. Keep the LoRa antenna
  attached. Use the intended private peer only for any deliberate send.
- Keep personal conversations, private channel keys/QR/share links, account
  pages and exact GPS coordinates out of the recording. Do not erase your
  history to make a video; pause or edit around navigation through private lists.
- Prefer a new clean conversation and harmless text such as “Demo message”.
  Check the whole frame for notifications, reflections and identifying labels.
- Avoid changing the active mesh profile, TX/privacy or phone settings for filming.
  A video does not require location sharing or a new public channel.

## Suggested shots

1. Start at the launcher. Open Cardputer Zero Mesh and show its main menu/header.
2. Open a clean message view and type a short message. If the intended peer is
   ready, send it and show its real delivery result. Otherwise show compose/cancel;
   never label an unconfirmed send as received.
3. Show Settings, the grouped Add a channel form and Cancel/Discard, without
   saving or showing secrets. Briefly open Diagnostics if its visible values are safe.
4. Return to the menu, hold Esc to exit and show the launcher again. Background
   radio operation may continue by design when it was left On; that permission
   is disclosed in the listing.

The main features need to be visible; every screen need not fit in one video.
Crop/blur private information before sharing. Do not show a private QR merely to
prove the camera works. GPS/map shots are optional if they would expose location.

## Before submission

Review the finished video yourself for readable screen text and private data.
Keep the original privately. After the submission is explicitly authorized and
its PR exists, attach the reviewed video in the PR comments. This checklist does
not upload, message maintainers or submit the app.
